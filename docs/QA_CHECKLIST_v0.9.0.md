# SatGeoTracker v0.9.0 — Favorites & Identity: проверка

Используйте новый каталог из полного ZIP. Не переносите старый `node_modules` и старый `public/cesium` между версиями. Для первой установки: `setup.cmd`, для запуска: `dev.cmd`.

## 1. Избранное

1. В режиме **КАРТА** найдите МКС (NORAD 25544), откройте инспектор и нажмите **☆ В ИЗБРАННОЕ**. Кнопка должна стать **★ В ИЗБРАННОМ**.
2. Выберите другой спутник (например WGS F9, NORAD 42075) и добавьте его. Нажмите ★ в верхнем меню. Должны быть две строки с именем и NORAD ID.
3. Введите `25544` или `ISS` в поиск списка. Остаётся только МКС. Очистите поиск и убедитесь, что обе строки снова видны.
4. Выберите спутник в избранном. Меню закрывается, открывается правый инспектор, камера переходит к нужному объекту, рабочая область переключается в **КАРТА**.
5. Обновите страницу (Ctrl+R) и перезапустите браузер. Избранное должно сохраниться.
6. Удалите спутник в списке с помощью `×`, затем убедитесь, что звёздочка в инспекторе стала пустой. Дублирование одного NORAD ID невозможно.
7. При временном отсутствии спутника в текущем загруженном каталоге запись остаётся в списке с пометкой «НЕТ В КАТАЛОГЕ»; переход отключён, удаление работает. Не нужно специально изменять каталог ради этой проверки.
8. Для проверки отказа localStorage (необязательно): блокируйте доступ к хранилищу через настройки браузера, добавьте спутник. Меню должно показывать предупреждение, не прерывая работу карты.

## 2. Компоновка и стиль

9. Справа полупрозрачный графитовый инспектор: при движении глобуса он заметен сквозь фон, но текст сохраняет читаемость. Прокрутка содержимого выполняется **внутри панели**, а не всей страницы.
10. В режиме **SDR** задайте наблюдателя и откройте инспектор выбранного спутника. Нижняя лента **РАДИОПРОЛЁТЫ** занимает ширину **до правого края окна**, включая пространство под инспектором. Нет пустого прямоугольника справа внизу.
11. Раскройте и сверните ленту пролётов; нижняя граница инспектора должна двигаться и оставаться на 12 px выше ленты на ПК.
12. Уберите координаты наблюдателя или переключитесь на **КАРТА**: отсутствие ленты не должно оставлять лишнюю пустую область и не должно ломать панель.
13. Проверьте разрешения 1920×1080, 1366×768 и ширину 390 px. На узком экране инспектор остаётся нижним листом, пролёты не перекрывают его.

## 3. Айдентика

14. В шапке виден знак Земли и орбитального кольца; рядом SatGeoTracker и версия **v0.9.0** (на мобильном версия может скрываться ради места).
15. Во вкладке браузера отображается новый фавикон. После обновления Ctrl+Shift+R и повторного запуска браузера он сохраняется.

## 4. Регрессия ядра

16. GEO (WGS F9), LEO (ISS), MEO (GPS): орбитальные линии не образуют ложные наземные петли.
17. Модель ISS без серого артефакта; маркеры обычных спутников янтарные, станции имеют отдельный значок.
18. Камера: сопровождение, ESC, Ctrl+колесо и Ctrl+0; поиск; SDR/пролёты; координаты наблюдателя и маски возвышения.
19. В DevTools → Console нет новых исключений загрузки `/cesium/Workers/*`.

## Команды автоматической проверки

```powershell
cd frontend
npm run check:cesium
npm run test:all
npm run build
```

В самом тестовом окружении, где собирался ZIP, выполнены `tsc -b` и тесты; сборку Vite на Windows нужно повторить отдельно после установки платформенных зависимостей.

**Зона вне изменений:** SGP4, орбитальная физика, CameraManager, прогнозы AOS/TCA/LOS, SDR backend и базы данных.
