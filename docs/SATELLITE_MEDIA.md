# SatGeoTracker v0.9.2 — Фотографии спутников

## Поведение

- **В КАРТА, SDR и ПРОЛЁТЫ** инспектор выбранного спутника запрашивает миниатюру по его NORAD ID через `/api/satellites/{norad_id}/media`.
- Не зависит от наличия радиоканалов. Не выполняет массовые запросы по всему каталогу.
- Если снимка нет, ошибку отдал SatNOGS или браузер не может загрузить файл, блок фотографии скрывается. Посторонние изображения не подставляются.
- Миниатюра является ссылкой на соответствующую карточку спутника SatNOGS DB. Изображение не используется в геометрии или в орбитальной физике SGT.

## API и кеш

- Источник: SatNOGS DB API `/api/satellites/?norad_cat_id=N&format=json`, поле `image`.
- Проверяется точное совпадение NORAD. Другие записи и произвольные небезопасные адреса изображений отклоняются.
- В отдельном кеше `%LOCALAPPDATA%\SatGeoTracker\cache\satellite-media` сохраняются только метаданные: успешные изображения на 24 часа, отсутствие фото на 6 часов.
- Сервер использует уже существующий HTTP-клиент FastAPI. Фотографии не перекачиваются через Backend, браузер загружает одобренные HTTPS-адреса SatNOGS.
- При временной ошибке применяется старый кеш. При отсутствии кеша возвращается `image_url: null` без сбоя интерфейса.
- React отменяет устаревшие запросы при смене выбранного объекта, ограничивает внутрисессионный кеш и не допускает отображение фото предыдущего NORAD ID.

## Проверка

1. Открой МКС (NORAD 25544) в режиме КАРТА. Если SatNOGS выдаёт изображение, оно видно справа от имени.
2. Переключись в SDR и ПРОЛЁТЫ, выбери другой спутник и убедись, что миниатюра не зависит от режима.
3. Найди объект без изображения: панели и размеры не должны ломаться, пустая рамка не остаётся.
4. Быстро переключай объекты и нажми на миниатюру: ссылка должна вести на страницу текущего NORAD ID SatNOGS.
5. Запусти `npm run test:all` и `python -m unittest discover -s backend/tests -v`.

Важно: SatNOGS не гарантирует фотографию каждого спутника; файлы принадлежат соответствующим авторам. Источник отображается на карточке.
