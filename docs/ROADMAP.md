# SatGeoTracker — План развития

**Текущая разрабатываемая версия: v0.9.2 (Satellite Media). Опубликованная стабильная: v0.9.1.** Здесь перечислены завершённые этапы и текущие задачи. Предыдущая подробная история сохранена в [архиве плана](ROADMAP_HISTORY.md) и [журнале изменений](../CHANGELOG.md).

## Реализовано

| Версия | Этап |
| --- | --- |
| v0.4–v0.5 | Система камеры, слежение за спутниками, 3D-визуализация Земли |
| v0.6 | Модель МКС в режиме выбранного спутника |
| v0.7 | Наземный наблюдатель, AOS/TCA/LOS, лента пролётов |
| v0.8 | SDR-данные, рабочие режимы, русский интерфейс, настройка FOV |
| v0.8.6–v0.8.8 | Исправление орбитальных линий, Cesium Workers, маркеров и модели МКС |
| v0.9.0 | Избранное, фирменное оформление, Graphite Glass, адаптивные панели |
| v0.9.1 | Универсальные карточки наведения, улучшения поиска и мобильной компоновки |

- **v0.9.2 (кандидат):** фотографии выбранных спутников из SatNOGS во всех режимах, без обязательного наличия фото и без массовой загрузки.

## Дальнейшие возможности

- [ ] Наземная трасса спутника, выделение предыдущих и будущих участков орбиты.
- [ ] Управление модельным временем для предварительного просмотра положения спутников.
- [ ] Расширение набора 3D-моделей при наличии подходящих ресурсов.

## Принципы проекта

- Для текущего локального MVP не нужны серверная база данных и регистрация. Избранное использует `localStorage`, внешние данные кешируются.
- В приоритете достоверность расчётов, скорость и понятный технический интерфейс.
- Этот список обозначает направления, а не фиксированные сроки релизов.
