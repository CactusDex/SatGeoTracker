SatGeoTracker v0.9.1 — архивные заметки о безопасной публикации в GitHub

СТАТУС: ПУБЛИКАЦИЯ УЖЕ ЗАВЕРШЕНА.
Версия v0.9.1 опубликована в основной ветке main. Этот файл оставлен
для истории исправления публикационного скрипта и не является
инструкцией, которую следует выполнять повторно.

Для первоначальной загрузки версии использовался временный клон Git,
а изменения отправлялись в release/v0.9.1 через Pull Request.

Меры безопасности, применённые в процедуре:
- Сохранён исходный .gitignore с правилами для .env, ключей, секретов
  и локальных баз данных.
- Исключено копирование кешей Cesium, node_modules, локальных настроек,
  конфиденциальных файлов и инструментов публикации.
- Перед коммитом выполнялась проверка git diff --cached --check.
- Не применялись force-push и прямой push в main.

Исторические проблемы и исправления:
1. Git предупреждал о переводе LF в CRLF. Это предупреждение,
   а не ошибка выполнения.
2. Первая публикация была остановлена из-за лишней пустой строки
   в конце frontend/tests/orbital-geometry.test.mjs. Она исправлена.
3. GitHub отклонил push с кодом GH007, потому что коммит содержал
   приватную почту автора. В коммите настроен адрес GitHub noreply.
4. Ветка release/v0.9.1 успешно загружена, Pull Request #2
   объединён с main.

Проверить историю:
https://github.com/CactusDex/SatGeoTracker/pull/2

Актуальные действия с GitHub следует выполнять через обычный Git
или Pull Request. Повторно запускать архивный скрипт публикации
только ради обновления README или документации не требуется.
