SatGeoTracker v0.9.0 - Favorites & Identity

1. Распакуйте ZIP в НОВУЮ папку.
2. Запустите setup.cmd (Node.js + Python 3 должны быть установлены).
3. Дождитесь успешной установки, затем запустите dev.cmd.
4. Откройте http://127.0.0.1:5173/ и обновите Ctrl+Shift+R.

Избранное: выберите спутник, нажмите звёздочку в правой панели.
Список: звёздочка в верхней панели. Хранение только в этом браузере.

Рекомендуемые проверки: docs/QA_CHECKLIST_v0.9.0.md
Проверка Cesium: check-cesium.cmd
Функциональные тесты: в папке frontend: npm run test:all
Сборка: в папке frontend: npm run build

Данные наблюдателя и избранное хранятся в localStorage браузера,
поэтому смена папки проекта сама по себе не стирает их, если адрес
приложения и профиль браузера не изменились.

Если v0.8.8 была установлена отдельно, не переносите из неё node_modules.
Вашу проверенную v0.8.8 рекомендуется сохранить как резервную копию.

GitHub main не менялся. Это кандидат на релиз до браузерного тестирования.
