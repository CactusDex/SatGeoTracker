SatGeoTracker v0.9.1 — локальный запуск (Windows)

1. Установите Node.js с npm и Python 3.
2. Склонируйте репозиторий или распакуйте полный архив в новую папку.
3. Запустите setup.cmd для первичной установки зависимостей.
4. Запустите dev.cmd.
5. Откройте http://127.0.0.1:5173/ (запуск может открыть адрес автоматически).

Для завершения работы: stop-dev.cmd.

ВОЗМОЖНОСТИ:
- КАРТА — 3D-глобус, слежение, орбиты и поиск.
- SDR — радиочастоты и данные передатчиков.
- ПРОЛЁТЫ — прогноз AOS/TCA/LOS для выбранного наземного наблюдателя.
- ИЗБРАННОЕ — звёздочка в инспекторе и в верхней панели.
- КАРТОЧКА НАВЕДЕНИЯ — сведения о спутнике при наведении курсора во всех трёх режимах.

Координаты наблюдателя и избранное сохраняются в localStorage того же браузера и профиля.
Они не удаляются при смене папки проекта, если адрес приложения остаётся прежним.

ПРОВЕРКИ:
- Frontend: cd frontend; npm run test:all
- Ресурсы Cesium: check-cesium.cmd
- Backend: python -m unittest discover -s backend/tests -v
- Production: cd frontend; npm run build
